# ASA DataFest 2026 — Best Insight Winner

🏆 Awarded “Best Insight” at ASA DataFest 2026 hosted at the University of Notre Dame.

## Overview

This project was developed during a 48-hour data analytics competition focused on exploring healthcare patient journey data from Northeast Kansas.
Our team analyzed over 390,000 respiratory healthcare encounters to better understand disparities in respiratory care access and emergency department reliance across different patient populations.
The project combined healthcare analytics, geospatial visualization, and exploratory data analysis to identify broader structural trends within the healthcare system.

## What We Explored

- Respiratory emergency department reliance by race and age
- Longitudinal healthcare encounter patterns
- Geographic disparities across Northeast Kansas
- Socioeconomic and environmental context
- Confounder analysis involving smoking status, seasonality, and time trends

## Tools & Technologies

- Python
- Google Colab
- Pandas
- Data Visualization
- Statistical Analysis
- Geospatial Analysis
